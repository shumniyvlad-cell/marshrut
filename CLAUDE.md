# Маршрут: полный разбор человека по дате рождения

Инструмент для цифровых психологов и астрологов. Эксперт вбивает имя, дату, время и место рождения клиента и получает разбор по семи системам плюс маршрут (делать / не делать / повторяющиеся сценарии / план на 90 дней) и обои на рабочий стол. Всё считается в браузере, клиенты хранятся в localStorage.

Стек как у SGX: React 19 + TypeScript + Vite, компоненты Astryx, своя тема `marshrut` (ультрамарин #2B31D0, фон #F2F3F8 / ночь #090A22, роза для «не делать» и Дизайна, шрифты Ysabeau + Ysabeau Office). Свой CSS только в `src/app.css`.

## Где что
- `src/engine/` — расчёты, без интерфейса:
  - `astro.ts` — планеты (astronomy-engine, тропический зодиак, эклиптика даты), истинный узел, дома Плацидуса (за полярным кругом Порфирий), аспекты;
  - `hd.ts` — Дизайн человека: мандала с 302°, Дизайн = Солнце на 88° раньше, центры, каналы, тип, авторитет, профиль, крест, Генные ключи;
  - `numbers.ts` — нумерология, Пифагор (после 2000 года третье число +19), Матрица судьбы по Ладини;
  - `bazi.ts` — четыре столпа (год с Ли Чунь, месяц по солнечным сезонам, день по JDN);
  - `time.ts` — местное время → UTC по IANA-поясу;
  - `route.ts` — сборка маршрута из всех систем.
- `src/content/*.json` — библиотека трактовок (~71 тыс. слов, на «вы», без рода). Грузится отдельным куском.
- `src/sections.tsx` — разделы разбора, `src/charts.tsx` — колесо, бодиграф, Матрица, Пифагор, `src/wall.ts` — обои на canvas.

## Проверка
`npm test` (эталоны: Обама — карта, Ра Уру Ху — Манифестор 5/1, Крест Клариона; 600 случайных дат — все трактовки на месте), `npx tsc -b && npm run build && npx astryx doctor --built dist && npm audit`.
Ошибочные состояния: `?fail=geo` (поиск городов), `?fail=lib` (библиотека трактовок). `?motion=1` — вращение неба при «Уменьшить движение».

## Правила окон (из промпта SGX)
- Формы — в BottomSheet, «Назад» телефона закрывает лист (`useSheetBack`).
- У экранов загрузка / ошибка с «Повторить» / пусто с действием / готово. Ошибки у поля и фокус на первое.
- Удаление через AlertDialog и тост «Вернуть».
- Новый компонент Astryx — дописать в `optimizeDeps.include` в vite.config.ts.
